# Produção Criativa — Dashboard v2

Site completo com **5 abas**, tema claro/escuro, frases motivacionais, conexões curvas, popups e pronto para uso (sem dados pré-preenchidos).

## Favicon
- `favicon.svg` — versão principal (criativa: P + calendário + brilhos)
- `favicon-v1.svg` … `favicon-v4.svg` — 4 variações SVG
- `favicon.ico` / `favicon-32.png` / `favicon-64.png` — formatos raster

Para trocar a versão principal, copie a desejada:
```bash
cp favicon-v2.svg favicon.svg
```
